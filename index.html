✨ ما الجديد في v2.0.0 — إصلاح جذري: تعديل/حذف المصروفات والمرتب يعملان الآن

  • إصلاح عاجل لتعديل/حذف المصروفات: قائمة الإجراءات (تعديل المبلغ / تعديل العنصر / حذف نهائي) كانت تفشل صامتة بخطأ تحقق داخلي (VerifyError) — أُعيد بناء الحوارات كاملة بخرائط سجلات صحيحة والقائمة تفتح وتعمل فعلياً الآن
  • إصلاح عاجل لتعديل/حذف المرتب الشهري: نفس الجذر في سجل آخر التغييرات — قائمة الإجراءات (تعديل المبلغ / حذف نهائي) تعمل الآن والرصيد يُعاد حسابه فوراً
  • زر «إلغاء» في كل حوارات التعديل والحذف: مستمع إلغاء نظامي جديد يغلق الحوار بأمان
  • أداة تدقيق آلي جديدة في خط البناء: فحص شامل لكل استدعاء (عدد السجلات مقابل توقيع المستدعى) على كامل التطبيق — صفر مخالفات في هذا الإصدار، وهذا النوع من الأخطاء مستحيل التسرب مستقبلاً
  • بقيت كل ميزات 1.9.9: حوار التحديث المنسق بالشعار، الترخيص، واتساب، والنص الجديد — وكل إصلاحات الإصدارات السابقة
  • ترقية مباشرة بنفس الشهادة

📲 التثبيت على الهاتف

  1. حمّل Masrofi-v2.0.0.apk من الزر أعلاه.
  2. افتح الملف وفعّل «التثبيت من مصادر غير معروفة» إن طُلب.
  3. أنشئ حساباً محلياً أو سجّل عبر Gmail.
  4. أضف راتبك وابدأ التسجيل.

🖥 التثبيت عبر ADB

  1. فعّل «تصحيح USB» من خيارات المطور.
  2. ثبّت بالأمر: adb install -r Masrofi-v2.0.0.apk
  3. لفرض التثبيت النظيف بعد تغيّر التوقيع: adb install -r -d بعد إزالة القديم.

✅ التحقق من سلامة الملف

  1. على الكمبيوتر: sha256sum Masrofi-v2.0.0.apk وقارن بالبصمة أعلاه.
  2. المطورون: apksigner verify --print-certs Masrofi-v2.0.0.apk
  3. الملف SHA256SUMS.txt بجانب الملفات يحوي كل البصمات.

🔄 التحديث التلقائي

  1. التطبيق يفحص التحديثات تلقائياً عند التشغيل.
  2. المصادر: GitHub raw ← jsDelivr CDN ← رابط احتياطي.
  3. مصدر الحقيقة: ملف update.json في المستودع.
