  1. فعّل «تصحيح USB» من خيارات المطور.
  2. ثبّت بالأمر: adb install -r Masrofi-v1.9.0.apk
  3. لفرض التثبيت النظيف بعد تغيّر التوقيع: adb install -r -d بعد إزالة القديم.
