■ التثبيت على الهاتف
----------------------------------------------------------
1. انقل Masrofi-v1.0.0.apk إلى الهاتف وافتحه.
2. فعّل "التثبيت من مصادر غير معروفة" إن طُلب منك.
3. ⚠ إن كانت لديك نسخة تجريبية سابقة: احذفها أولاً لأن
   مفتاح التوقيع الحالي جديد ولا يقبل التثبيت فوق القديم.
4. أنشئ حساباً محلياً أو اختر حساب Gmail، ثم أضف راتبك وابدأ.

■ التثبيت عبر ADB (للمطورين)
----------------------------------------------------------
   adb install -r Masrofi-v1.0.0.apk

■ التعديل عبر apktool
----------------------------------------------------------
1. فك الحزمة:    unzip Masrofi-apktool-decoded.zip
2. عدّل ما تريد، أشهر التعديلات:
   - الألوان:      decoded/res/values/colors.xml
   - اسم التطبيق:  decoded/res/values/strings.xml
   - الأيقونة:     استبدل decoded/res/mipmap-*/ic_launcher.png
   - الأنشطة والدفع: عدّل Smali أو الأفضل عدّل المصدر Java
3. أعد البناء:   apktool b decoded -o new.apk
4. وقّع:
   keytool -genkeypair -v -keystore my.keystore -alias mykey \
     -keyalg RSA -keysize 2048 -validity 10000
   apksigner sign --ks my.keystore --out signed.apk new.apk

■ إعادة البناء من الكود المصدري (بدون Gradle)
----------------------------------------------------------
1. فك: unzip Masrofi-source-code.zip && cd masrofi-source
2. جهّز الأدوات: JDK 17 + build-tools 34 + platform android-34
3. عدّل المسارات أعلى build.sh ثم نفّذ:  bash build.sh
4. المفتاح masrofi.keystore مرفق (كلمة السر: Masrofi@2026)
   ⚠ احفظه جيداً — التحديثات الجديدة يجب أن تُوقّع بنفس المفتاح.

■ تفعيل فحص التحديثات داخل التطبيق
----------------------------------------------------------
1. ارفع APK + update.json على استضافة (GitHub Releases مثلاً).
2. عدّل الرابط في: src/.../UpdateChecker.java  →  UPDATE_URL
3. حدّث versionCode في update.json وفي AndroidManifest.xml عند كل إصدار.
4. التطبيق سينزّل الإصدار الجديد تلقائياً عبر DownloadManager.
